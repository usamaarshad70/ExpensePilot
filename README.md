# ExpensePilot

ExpensePilot is a modern personal finance management application built with React.js and Tailwind CSS. It helps users manage income, expenses, categories, and financial reports through an intuitive and responsive interface.

## 🚀 Features

- Add, Edit, and Delete Transactions
- Income & Expense Tracking
- Category Management
- Dashboard Analytics
- Interactive Charts & Reports
- Monthly Statistics
- Search & Filter Transactions
- Dark / Light Mode
- CSV Export
- Responsive Design (Desktop & Mobile)
- Local Storage Persistence

## 🛠️ Tech Stack

- React.js
- JavaScript (ES6+)
- Tailwind CSS
- React Router DOM
- Context API
- Recharts
- React Hot Toast
- Vite

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/usamaarshad70/ExpensePilot.git
```

Navigate to the project folder:

```bash
cd ExpensePilot
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
